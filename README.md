# Tugas Pintar

Aplikasi To-Do List ringkas dalam Bahasa Melayu.

## Fungsi
- Tambah tugasan
- Keutamaan rendah, sederhana dan tinggi
- Tarikh akhir
- Tandakan tugasan selesai
- Padam tugasan
- Tapis semua / belum siap / selesai / keutamaan tinggi
- Simpan automatik dalam browser menggunakan localStorage

## Jalankan
Buka `index.html` dalam browser atau deploy repository ini ke Vercel.
